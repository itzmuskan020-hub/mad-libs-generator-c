 Mad Libs Story Generator in C
 
About the Project:
A beginner-friendly C programming project that generates a funny story using words entered by the user.

Features:
* Accepts user input
* Generates a personalized story
* Uses basic C programming concepts
* Simple and interactive console interface

Concepts Used:
* Variables and character arrays
* `printf()` and `scanf()`
* String handling
* Basic input and output

How to Run:
1. Download `madlibs.c`.
2. Open it in a C compiler such as GCC or Code::Blocks.
3. Compile and run the program.
4. Enter the requested words and enjoy your story!

Language:
C

Author:
